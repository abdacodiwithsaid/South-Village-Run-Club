# 100 Coding Project Ideas for All Levels

Looking for inspiration for your next coding project? This list offers a diverse range of ideas, spanning various domains and difficulty levels – from beginner-friendly tasks to more advanced challenges. Whether you're interested in web development, mobile apps, data science, game development, or emerging fields like blockchain and IoT, there's something here to spark your creativity and help you build your skills. Each idea is designed to be a practical, fun, or educational exercise.

## Web Development

### Frontend
1.  **Web Development (Frontend):** Build a simple calculator using HTML, CSS, and JavaScript. (Beginner)
2.  **Web Development (Frontend):** Create a responsive image gallery using CSS Grid or Flexbox and JavaScript. (Beginner)
3.  **Web Development (Frontend):** Develop a quiz application that fetches questions from a local JSON file. (Beginner)
4.  **Web Development (Frontend):** Design a personal portfolio website with multiple sections (About, Projects, Contact) using React or Vue.js. (Intermediate)
5.  **Web Development (Frontend):** Build a weather application that fetches data from a public API and displays the current weather and forecast. (Intermediate)
6.  **Web Development (Frontend):** Create a markdown previewer where users can type markdown and see the HTML rendering in real-time. (Intermediate)
7.  **Web Development (Frontend):** Develop a Kanban board application with drag-and-drop functionality for tasks. (Advanced)
8.  **Web Development (Frontend):** Build a real-time chat application using WebSockets (e.g., Socket.io) and a frontend framework. (Advanced)

### Backend
9.  **Web Development (Backend):** Create a simple REST API with Node.js/Express.js or Python/Flask that serves JSON data. (Beginner)
10. **Web Development (Backend):** Develop a URL shortener service with a database to store the mappings. (Intermediate)
11. **Web Development (Backend):** Build a web scraper to collect data from a website and store it in a CSV file or database (respect robots.txt). (Intermediate)
12. **Web Development (Backend):** Implement user authentication (login, registration, password hashing) for a web application using JWT or sessions. (Intermediate)
13. **Web Development (Backend):** Design and develop a blogging platform API with CRUD operations for posts and comments. (Advanced)

### Fullstack
14. **Web Development (Fullstack):** Build a to-do list application with a React frontend and a Node.js/Express.js backend with database persistence. (Intermediate)
15. **Web Development (Fullstack):** Create a book tracking application where users can add books they've read, are reading, or want to read. (Intermediate)
16. **Web Development (Fullstack):** Develop an e-commerce site with product listings, a shopping cart, and user accounts (mock payment). (Advanced)
17. **Web Development (Fullstack):** Build a social media dashboard that aggregates posts from multiple platforms for a user. (Advanced)
