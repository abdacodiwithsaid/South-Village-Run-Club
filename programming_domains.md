# Programming Domains and Associated Technologies

## Web Development

### Frontend
- **Programming Languages:** JavaScript, TypeScript, HTML, CSS
- **Frameworks & Libraries:** React, Angular, Vue.js, Svelte, jQuery, Bootstrap, Tailwind CSS
- **Tools & Platforms:** VS Code, Webpack, Babel, npm/yarn, Figma, Chrome DevTools

### Backend
- **Programming Languages:** Node.js (JavaScript), Python, Java, Ruby, PHP, Go, C#
- **Frameworks & Libraries:** Express.js (Node.js), Django/Flask (Python), Spring (Java), Ruby on Rails (Ruby), Laravel (PHP), Gin (Go), .NET (C#)
- **Tools & Platforms:** Docker, Kubernetes, PostgreSQL, MySQL, MongoDB, Redis, Nginx, Apache, Postman, AWS, Azure, Google Cloud

### Fullstack
- **Programming Languages:** JavaScript/TypeScript (often with Node.js for backend), Python, Ruby, Java, C#
- **Frameworks & Libraries:** MERN (MongoDB, Express.js, React, Node.js), MEAN (MongoDB, Express.js, Angular, Node.js), Django/Flask + React/Vue, Ruby on Rails + React/Vue, Spring Boot + Angular/React, ASP.NET + React/Angular
- **Tools & Platforms:** Combines frontend and backend tools. Git, GitHub/GitLab, CI/CD pipelines (Jenkins, GitLab CI, GitHub Actions)

## Mobile App Development

### iOS
- **Programming Languages:** Swift, Objective-C
- **Frameworks & Libraries:** UIKit, SwiftUI, Combine, Core Data, Alamofire
- **Tools & Platforms:** Xcode, TestFlight, CocoaPods, Swift Package Manager

### Android
- **Programming Languages:** Kotlin, Java
- **Frameworks & Libraries:** Android Jetpack (Compose, ViewModel, LiveData, Room), Retrofit, Kotlin Coroutines
- **Tools & Platforms:** Android Studio, Gradle, Firebase, Google Play Console

### Cross-platform
- **Programming Languages:** JavaScript/TypeScript, Dart, C#
- **Frameworks & Libraries:** React Native, Flutter, Xamarin, Ionic, NativeScript
- **Tools & Platforms:** VS Code, Android Studio, Xcode (for building/testing iOS), npm/yarn, Pub (for Flutter)

## Data Science & Machine Learning
- **Programming Languages:** Python, R, SQL, Scala, Julia
- **Frameworks & Libraries:**
    - **Python:** NumPy, Pandas, Scikit-learn, TensorFlow, PyTorch, Keras, Matplotlib, Seaborn, SciPy, Statsmodels
    - **R:** dplyr, ggplot2, caret, tidyverse
- **Tools & Platforms:** Jupyter Notebooks/JupyterLab, RStudio, Apache Spark, Hadoop, Kubeflow, MLflow, Tableau, Power BI, AWS SageMaker, Google AI Platform, Azure Machine Learning

## Game Development
- **Programming Languages:** C++, C#, Lua, Python (for scripting)
- **Frameworks & Libraries:**
    - **Engines:** Unreal Engine (C++), Unity (C#), Godot Engine (GDScript, C#, C++)
    - **Libraries:** SDL, SFML, Pygame (Python)
- **Tools & Platforms:** Blender, Maya, 3ds Max, Photoshop, Aseprite, FMOD, Wwise, Steam, Epic Games Store

## Automation & Scripting
- **Programming Languages:** Python, Bash, PowerShell, Ruby, Perl
- **Frameworks & Libraries:**
    - **Python:** Selenium, BeautifulSoup, Requests, Paramiko, Ansible (for IT automation)
    - **Bash/PowerShell:** Built-in commands and scripting capabilities
- **Tools & Platforms:** Cron (Linux), Task Scheduler (Windows), Jenkins, GitLab CI, GitHub Actions, Docker

## Cybersecurity
- **Programming Languages:** Python, C/C++, Go, Ruby, PowerShell, Bash
- **Frameworks & Libraries:**
    - **Python:** Scapy, Nmap (python-nmap), Requests, Metasploit Framework (Ruby)
    - **Security Tools:** Wireshark, Burp Suite, Nessus, Snort, Kali Linux distribution
- **Tools & Platforms:** SIEM systems (Splunk, ELK Stack), IDS/IPS, Firewalls, Vulnerability Scanners

## Internet of Things (IoT)
- **Programming Languages:** C/C++, Python, MicroPython, Java, JavaScript (Node.js for gateways/servers)
- **Frameworks & Libraries:** Arduino SDK, ESP-IDF (for ESP32), Raspberry Pi libraries (RPi.GPIO), MQTT libraries (Paho), CoAP libraries
- **Tools & Platforms:** Arduino IDE, PlatformIO, Raspberry Pi, ESP32/ESP8266 boards, AWS IoT, Azure IoT Hub, Google Cloud IoT Core, MQTT Brokers (Mosquitto)

## Desktop Applications
- **Programming Languages:** C++, C#, Java, Python, Swift (macOS), Kotlin (cross-platform with Compose for Desktop)
- **Frameworks & Libraries:**
    - **C++:** Qt, wxWidgets
    - **C#:** .NET (WPF, Windows Forms), Avalonia UI
    - **Java:** JavaFX, Swing
    - **Python:** Tkinter, PyQt, Kivy
    - **Cross-Platform:** Electron (JavaScript, HTML, CSS), Tauri (Rust, web frontend)
- **Tools & Platforms:** Visual Studio, Qt Creator, IntelliJ IDEA, Eclipse, Xcode

## Cloud Computing
- **Programming Languages:** Python, Go, Java, C#, Node.js (JavaScript), Ruby
- **Frameworks & Libraries:**
    - **SDKs for Cloud Providers:** AWS SDK (Boto3 for Python), Azure SDK, Google Cloud Client Libraries
    - **Infrastructure as Code:** Terraform, AWS CloudFormation, Azure Resource Manager (ARM) templates, Pulumi
    - **Serverless Frameworks:** Serverless Framework, AWS SAM
    - **Containerization:** Docker, Kubernetes (often managed via cloud provider services like EKS, AKS, GKE)
- **Tools & Platforms:** AWS (EC2, S3, Lambda, RDS, etc.), Microsoft Azure (VMs, Blob Storage, Functions, SQL Database, etc.), Google Cloud Platform (Compute Engine, Cloud Storage, Cloud Functions, Cloud SQL, etc.), Docker Desktop, kubectl

## Blockchain
- **Programming Languages:** Solidity (Ethereum), Rust (Solana, Polkadot), Go (Hyperledger Fabric), JavaScript/TypeScript (interacting with chains, DApp frontends)
- **Frameworks & Libraries:**
    - **Ethereum:** Hardhat, Truffle, Web3.js, Ethers.js, OpenZeppelin Contracts
    - **Other Chains:** Anchor (Solana), Substrate (Polkadot)
- **Tools & Platforms:** Remix IDE, Ganache, MetaMask, Infura, Alchemy, Tenderly, Etherscan, Various blockchain explorers

## AI & Robotics (beyond general ML)
- **Programming Languages:** Python, C++, LISP (historically), Prolog (logic programming)
- **Frameworks & Libraries:**
    - **Robotics:** ROS (Robot Operating System), OpenCV (computer vision), PCL (Point Cloud Library)
    - **AI Planning & Reasoning:** PDDL (Planning Domain Definition Language) parsers/solvers, Answer Set Programming (ASP) libraries
    - **Natural Language Processing (Advanced):** spaCy, NLTK (beyond basic ML use), Transformers (Hugging Face) for complex models
- **Tools & Platforms:** Gazebo (robotics simulation), CoppeliaSim (V-REP), NVIDIA Isaac SDK, specific hardware SDKs (e.g., for robot arms, drones)

## Educational Technology (EdTech)
- **Programming Languages:** JavaScript, Python, Ruby, PHP, Java
- **Frameworks & Libraries:**
    - **Web:** React, Angular, Vue.js, Django, Ruby on Rails, Laravel
    - **LMS Platforms/Standards:** Moodle (PHP), Canvas (Ruby), SCORM, xAPI (Tin Can API)
- **Tools & Platforms:** Articulate 360, Adobe Captivate, H5P, Various Learning Management Systems (LMS), Student Information Systems (SIS)

## Healthcare Technology (HealthTech)
- **Programming Languages:** Python, Java, C#, JavaScript, Swift/Kotlin (for mobile health apps), Mumps (M) (legacy systems)
- **Frameworks & Libraries:**
    - **Interoperability:** HL7 (FHIR, v2) libraries (e.g., HAPI FHIR for Java, fhir.py for Python)
    - **Imaging:** DICOM libraries (pydicom for Python, dcmtk for C++)
    - **Web/Mobile frameworks** for patient portals and apps.
- **Tools & Platforms:** EHR/EMR systems (Epic, Cerner - often proprietary), PACS (for medical imaging), Telehealth platforms, Medical imaging viewers, Compliance tools (HIPAA)

## Fintech (Financial Technology)
- **Programming Languages:** Python, Java, C++, Go, JavaScript/TypeScript, Scala
- **Frameworks & Libraries:**
    - **Quantitative Finance (Python):** NumPy, Pandas, SciPy, QuantLib
    - **Trading APIs:** Libraries for interacting with brokerage APIs (e.g., Interactive Brokers API, Alpaca API)
    - **Backend Frameworks:** Spring Boot (Java), Django/Flask (Python), Express.js (Node.js) for robust and secure backends
    - **Blockchain technologies** (see Blockchain section) if dealing with crypto.
- **Tools & Platforms:** FIX Protocol tools, Bloomberg Terminal (data & analytics), Refinitiv Eikon, Payment gateways (Stripe, PayPal APIs), Low-latency trading infrastructure, Security and compliance platforms (PCI DSS).
